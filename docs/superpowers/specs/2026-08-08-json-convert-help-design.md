## 工具简介

开头说明：

- `json-convert` 是文件到文件的双向转换命令；
- `--out json5` 表示严格标准 JSON 转本项目扩展 JSON5；
- `--out json` 表示本项目支持的 JSON5 转严格标准 JSON；
- 反引号字符串是本项目扩展，不是标准 JSON5；
- 其他 JSON5 实现可能拒绝转换器生成的反引号字符串。

## 快速开始

提供两条可直接执行的命令：

```bash
go run ./cmd/json-convert --out json5 --indent 2 input.json output.json5
go run ./cmd/json-convert --out json --indent 2 input.json5 output.json
```

补充紧凑输出：

```bash
go run ./cmd/json-convert --out json5 --indent 0 input.json output.json5
```

## 命令语法与参数

展示语法：

```text
json-convert --out json|json5 [--indent 0..8] INPUT OUTPUT
```

参数表：

| 参数 | 必填 | 默认值 | 说明 |
|---|---:|---:|---|
| `--out` | 是 | 无 | `json5`：JSON → JSON5；`json`：JSON5 → JSON |
| `--indent` | 否 | `2` | `0` 为紧凑输出，`1–8` 为每层空格数 |
| `INPUT` | 是 | 无 | 输入文件路径 |
| `OUTPUT` | 是 | 无 | 输出文件路径 |

说明：

- 必须恰好提供两个位置参数；
- `--out` 只允许 `json` 和 `json5`；
- `--indent` 只允许整数 `0–8`；
- 现有 `--help` 保持简洁，不复制 README 的完整规则。

## 退出码与输出行为

说明：

- 成功退出码为 `0`；
- 读取、解析、转换或写入失败返回 `1`；
- 参数错误返回 `2`；
- 成功时不向 stdout 输出转换内容；
- 错误写入 stderr；
- 输出文件末尾始终包含一个 LF；
- `--indent 0` 只压缩结构空白，不移除文件末尾 LF。

## JSON 转 JSON5

### 输入要求

`--out json5` 的输入是严格标准 JSON。

可以转换：

- 对象、数组、字符串、数字、布尔值和 `null`；
- 重复对象键；
- 任意嵌套结构；
- 标准 JSON 字符串转义；
- 大整数和高精度数字文本；
- Unicode 和合法 UTF-16 surrogate pair。

以下输入会报错：

- 注释；
- 单引号或反引号字符串；
- 未加引号对象键；
- 尾随逗号；
- 十六进制数字；
- 前导 `+`；
- `.5`、`1.`；
- `Infinity`、`NaN`；
- 未转义控制字符；
- 无效 UTF-8；
- 顶层值后的额外内容。

### 输出规则

- 对象成员顺序和重复键保持不变；
- 数字原始文本保持不变，不经过 `float64`；
- 对象键始终使用标准双引号；
- 不含反引号的字符串值使用反引号；
- 含反引号的字符串值回退为标准 JSON 双引号；
- raw string 内的单引号、双引号、反斜杠、实际换行和控制字节保持解码后的字节；
- `--indent` 只调整结构空白，不改变 raw string 内容。

内嵌完整输入和输出示例，覆盖多行脚本、含反引号字符串和 `1.2300` 数字原文。

## JSON5 转 JSON

### 可接受输入

`--out json` 接受：

- 双引号、单引号和反引号字符串值；
- 双引号、单引号和合法未加引号对象键；
- `//` 行注释和 `/* ... */` 块注释；
- 对象和数组尾随逗号；
- 十六进制数字；
- 前导 `+`；
- 前导或尾随小数点；
- 标准 JSON 值和嵌套结构；
- 重复键和原始成员顺序。

### 输出规则

- 键和值字符串统一输出为标准 JSON 双引号；
- 引号、反斜杠、换行和控制字符按标准 JSON 转义；
- 尾随逗号被删除；
- 顺序和重复键保持不变；
- 输出保证是严格标准 JSON，可被 `encoding/json` 等标准解析器读取；
- 所有输出字符串和对象键必须是有效 UTF-8。

### 数字表

| JSON5 输入 | JSON 输出 |
|---|---|
| `0xFF` | `255` |
| `-0xFF` | `-255` |
| `+12` | `12` |
| `.5` | `0.5` |
| `-.5` | `-0.5` |
| `1.` | `1.0` |
| `+1.` | `1.0` |
| 标准十进制或指数 | 保留原文 |
| `Infinity` / `±Infinity` | 报错 |
| `NaN` / `±NaN` | 报错 |

说明十六进制使用任意精度整数，不经过 `int64` 或 `float64`。

### 无法转换

明确列出：

- `Infinity`、`+Infinity`、`-Infinity`；
- `NaN` 及带符号形式；
- 含无效 UTF-8 的字符串或对象键；
- 未闭合 quoted/raw string 或块注释；
- 反引号对象键；
- 非法数字 token；
- 顶层值后的额外内容。

## 注释转 `_hint`

说明该行为只发生在 JSON5 → JSON。

会关联：

- 对象成员前的一个或多个注释；
- 与成员值结束位置同一行的注释；
- 逗号前或逗号后的同行注释；
- 多行 raw string、对象或数组结束行后的同行注释。

不会关联：

- 顶层注释；
- 数组元素注释；
- 对象最后成员后另起一行的尾部注释；
- 其他无法关联对象成员的注释。

归属规则：

- 前置注释和字段之间的空白行不打断关联；
- 多个前置注释按源码顺序；
- 前置在前，行尾在后，以换行连接；
- 与前一成员结束位置同行时优先归前一成员；
- 每条注释最多归属一次。

字段规则：

- hint 紧邻原字段并位于其前；
- 字段名直接追加 `_hint`；
- `name_hint` 的说明生成 `name_hint_hint`；
- 已存在同名字段时允许重复键，不合并、不覆盖。

注释正文清理规则：删除定界符、首尾空白行、公共缩进和每行可选 `*` 前缀，保留正文换行。

提供前置和行尾注释合并的输入、输出示例。

## 反引号 raw string 注意事项

强调：

- 反引号字符串不是标准 JSON5；
- 只允许作为值，不允许作为对象键；
- 第一个反引号结束字符串；
- 内容中无法包含反引号，也没有反引号转义；
- `\n`、`\t`、`\uXXXX` 都是普通字节，不解释；
- LF、CRLF 和单独 CR 逐字节保留；
- JSON → JSON5 时，含反引号的字符串自动回退双引号。

## 顺序与重复键

说明：

- 转换器使用有序语法树，保留成员顺序和重复键；
- `_hint` 也可能产生重复键；
- 许多下游程序解码到 map 时只保留最后一个重复键；
- 用户必须确认下游系统对重复键的处理符合预期。

## 文件安全

说明：

- 禁止原地转换；
- 路径不同但指向同一 hard link 或 symlink 目标时也拒绝；
- 输出路径只能不存在或是普通文件；
- 目录、symlink 和其他非普通文件拒绝覆盖；
- 转换完整成功后才替换输出文件；
- 失败时保留已有输出文件；
- 极端替换和恢复同时失败时，错误中提供保留的备份路径。

## 常见错误

- `invalid UTF-8 in string`；
- `refuse to replace non-regular output`；
- `unterminated raw string`；
- 严格 JSON 输入含 JSON5 语法。
